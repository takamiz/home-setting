# Global Rules

## Language

- All chat messages to the user must be in Japanese.
- All rules and instructions (including this file) must be written in English.
- All documentation files (README, plans, design docs, etc.) must be written in Japanese.
- All source code (variable names, comments, strings, identifiers) must be written in English.

## Git

- Never add `Co-Authored-By` trailers to commit messages.

## Workflow

- Do not ask for confirmation before taking actions. Proceed immediately with the task.
- Maintain a journal file at `<project>/.claude/journal/YYYY-MM-DD.md` to track work progress.
  - Log each task started, key decisions made, and steps completed.
  - On resume, read the latest journal entry to restore context and continue.
